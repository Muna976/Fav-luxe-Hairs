# FAV LUXE Hair & Nail Care Website

A simple, modern, luxury-style static website built with HTML, CSS and JavaScript.

## Included
- Responsive landing page
- FAV LUXE branding
- Services section
- 7 hair-design inspiration cards
- Hair design filters
- Image lightbox
- WhatsApp booking buttons
- Booking form that creates a WhatsApp message
- "Our Queens" customer gallery
- Upload customer hair photo + name + hairstyle
- LocalStorage persistence for the demo gallery

## Run
Open `index.html` in a browser.

For best results, run it through a local server such as VS Code Live Server.

## Important
The 7 hair-design cards currently use external web image URLs for inspiration. Before launching commercially, replace them with photos owned by FAV LUXE or images for which you have appropriate usage rights.

The "Our Queens" uploader is a browser/localStorage demo. For a real production admin system that works across devices, connect the uploader to a backend/storage service such as Supabase or Firebase.
